## 一、專案簡介

我的幸運物是**家裡養的白色貓咪**。牠的存在為家中帶來好運與陪伴；牠很愛吃，所以胖胖的，讓我覺得牠很有福氣。我希望可以一直陪伴著牠。

這個網頁以「故事」為主軸，搭配文字說明與 SVG 向量插畫，介紹幸運物的**由來**與**象徵意涵**，並加入滑鼠懸停、點擊、捲動等互動動畫，讓瀏覽的人可以「摸摸牠、餵牠、抱抱牠」。

## 二、專案儲存方式

### 1. 資料夾命名規則

整個專案放在一個以 **「學號_名字」** 命名的資料夾中：

```
514170260_蔡杰紘
```

這樣繳交或壓縮成 `514170260_蔡杰紘.zip` 時，老師可以直接從資料夾名稱辨識是誰的作業。

### 2. 資料夾結構

```
第三週/
└── 514170260_蔡杰紘/            ← 專案根目錄（學號_名字）
    ├── index.html               ← 主頁面：網頁結構與文字內容、白貓 SVG 插畫
    ├── README.md                ← 專案說明文件（本檔案）
    ├── css/
    │   └── style.css            ← 樣式表：配色、字型、版面、RWD、所有 CSS 動畫
    ├── js/
    │   └── script.js            ← 互動腳本：懸停／點擊／捲動效果、餵食小遊戲
    └── images/
        └── favicon.svg          ← 瀏覽器分頁上的小貓圖示
```

### 3. 儲存原則

| 原則 | 說明 |
| --- | --- |
| 結構、樣式、行為分離 | HTML 只放內容與結構，CSS 放在 `css/`，JavaScript 放在 `js/`，方便維護與批改。 |
| 使用相對路徑 | `index.html` 以 `css/style.css`、`js/script.js`、`images/favicon.svg` 相對路徑引用，整個資料夾搬到任何電腦都能直接開啟。 |
| 檔名一律英文小寫 | 避免不同作業系統或伺服器對中文、大小寫檔名的相容問題。 |
| 圖像以 SVG 向量繪製 | 白貓、食物、圖示等插畫都用 SVG 寫在 HTML 中，不需要外部圖片檔，放大也不會失真，檔案也很小。 |
| 字型由 Google Fonts 載入 | 標題使用「霞鶩文楷 LXGW WenKai TC」、內文使用「思源黑體 Noto Sans TC」；若離線，會自動改用電腦內建的楷體與黑體。 |
| 互動紀錄存在瀏覽器 | 「福氣值」、摸摸次數、擁抱次數存在瀏覽器的 `localStorage`，重新整理後仍會保留，只存在自己的電腦，不會上傳到任何地方。 |

## 三、如何開啟

1. 打開 `514170260_蔡杰紘` 資料夾。
2. 用瀏覽器（建議 Chrome、Edge、Safari 或 Firefox 最新版）直接開啟 **`index.html`** 即可，不需要安裝任何東西。
3. 想要清除互動紀錄時，可以在瀏覽器的開發者工具中清除此網頁的 localStorage。

## 五、互動效果規劃

### 滑鼠懸停（Hover）

| 位置 | 效果 |
| --- | --- |
| 白貓（主視覺、餵食區、大頭照） | 歪頭、臉頰變紅、尾巴搖得更快、耳朵抖動 |
| 白貓的眼睛 | 眼睛與頭部會**跟著滑鼠方向**轉動 |
| 導覽列連結／Logo 印章 | 背景淡入、印章旋轉放大 |
| 關鍵字標籤 | 往上彈起並微微傾斜 |
| 按鈕 | 上浮＋漸層色（紅→金）淡入 |
| 拍立得大頭照 | 轉正並放大 |
| 檔案卡印章 | 旋轉放大 |
| 故事章節卡片 | 卡片上浮、圖示旋轉、章節大字浮水印位移 |
| 象徵卡片 | 依滑鼠位置做 **3D 傾斜**＋光澤跟著移動 |
| 點心按鈕 | 上浮、點心圖示左右搖擺 |
| 熟睡白貓 | 耳朵抖動、臉紅 |

### 點擊（Click）

| 位置 | 效果 |
| --- | --- |
| 主視覺白貓 | 身體彈跳擠壓、鈴鐺搖晃、眼睛瞇成 ^ ^、對話泡泡隨機說話、愛心噴發、福氣值 +1 |
| 所有按鈕 | 從點擊位置擴散的**漣漪動畫** |
| 象徵卡片 | **3D 翻面**，顯示背面的意涵說明 |
| 點心按鈕 | 點心沿弧線**飛進貓咪嘴裡**（飛行時貓咪眼睛會盯著點心）、嘴巴咀嚼、飽足度增加、貓咪身體變圓 |
| 抽福籤 | 籤卡翻面顯示隨機福籤＋彩紙與金幣噴發 |
| 擁抱按鈕／熟睡白貓 | 貓咪被抱緊的擠壓動畫、愛心飄出、顯示溫暖的話 |
| 頁面空白處 | 留下一個慢慢消失的**貓咪肉球腳印** |

### 捲動與待機動畫

- **捲動進度條**：頁面最上方的金紅色細線，顯示閱讀進度。
- **區塊淡入**：各區塊進入畫面時淡入；故事章節左右交錯滑入。
- **導覽列定位**：自動標示目前閱讀到的區塊。
- **待機動畫**：白貓會眨眼、呼吸、搖尾巴、偶爾抖耳朵；熟睡白貓會點頭並冒出 Zzz；夜空星星閃爍。

### 無障礙與相容

- 所有可點擊的元素都是 `<button>` 或 `<a>`，可以用鍵盤 Tab 選取、Enter／空白鍵觸發。
- 若系統開啟「減少動態效果」，網頁會自動關閉大部分動畫。
- 支援手機、平板與桌機（RWD 響應式版面）。
